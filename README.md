# Larry's Auto Repair — Website

Website for Larry's Auto Repair: *Where quality meets affordability.*

Plain HTML, CSS and JavaScript, so it runs on GitHub Pages and on any regular web host.

## Pages
- `index.html` — Home (hero, services preview, why us, reviews)
- `services.html` — Full list of services with starting prices
- `contact.html` — Shop info, hours, quote request form, map

## Things to fill in
Search the files for `PLACEHOLDER` to find each spot:
- Phone number, address, email, hours (in every page's top bar and footer)
- "Starting at $XX" prices on the services page
- The numbers in "Repairs You Can Trust" on the home page
- Real customer reviews on the home page
- The Google Map on the contact page
- The quote form: make a free Formspree account, then replace `YOUR_FORM_ID` in `contact.html`

## Preview it on your computer
Open `index.html` in a browser.

## Moving to a real host later
Copy all the files to the new host, or connect this repo to Netlify, Vercel or Cloudflare Pages.
All links are relative, so nothing needs to change.
